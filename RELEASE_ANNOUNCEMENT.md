# Short Release Announcement

## SICK OLLIE CREATOR STUDIO + TOOLKIT v3 — the big Studio update

SICK OLLIE has grown from a node pack into a connected ComfyUI production system. This release brings together the expanded Studio Nodes, a visual LoRA Library, prompt-first Recipe Catalog, Yearbook LoRA testing, and integrated LoRA and Prompt Log organizers inside one SOS sidebar hub.

Loader Core now handles review states, color-coded filters, safer trigger discovery, info buttons, and multi-LoRA stacks. Prompt Core adds reusable `NAME` / `OUTFIT` / `SCENE` / `ITEM` or `BRAND` / `TRIGGER` assembly. Preview can pin and compare results, save Library thumbnails, or capture the exact displayed setup as a Recipe. Output and Metadata preserve the context needed to understand and reuse what actually ran.

There are dozens of smaller improvements too: Favorite/Keep/Retest/Reject LoRA states, dimension swap, copy feedback, missing-log recovery, safer Yearbook stopping, metadata-aware imports, recoverable quarantine, preview-first organizers, and a much clearer starter experience.

If you used the first Studio Nodes release, this is the release that turns those ideas into a full creator toolkit. Older Classic Preview nodes upgrade automatically to Studio Preview when their workflows open, preserving their wiring and settings.

**Install:** replace the old `ComfyUI-SickOllie` folder with the new release, keep your `ComfyUI/user/SickOllie/` and `ComfyUI/input/SickOllieLogs/` data, restart ComfyUI, and hard-refresh the browser.
