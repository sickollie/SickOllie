WORKFLOWS
---------
Drag either current workflow onto the ComfyUI canvas:

    Starter Content/workflows/Sick Nodes v2_Studio.json
    Starter Content/workflows/Sick Nodes v2_Classic.json

    SickOllie_NodePack.json
    is a convenience copy of the current Studio starter.

The workflows are already wired. Select model, text-encoder, VAE, and LoRA
files installed on your machine before queueing.

PROMPT AND OUTFIT LOGS
----------------------
Copy this folder:

    Starter Content/input/SickOllieLogs

into your ComfyUI input folder so the final path is:

    ComfyUI/input/SickOllieLogs

The included library contains:
- prompt-log examples, including placeholder-driven templates
- six outfit-log files
- one scene-insert log

After copying the logs:
1. Restart ComfyUI.
2. Hard-refresh the browser with Ctrl+F5.
3. Reopen Prompt Core and select the desired log from its dropdown.
