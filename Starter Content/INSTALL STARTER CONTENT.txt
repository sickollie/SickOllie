SICK OLLIE STARTER CONTENT

WORKFLOW
--------
Open or drag this file into ComfyUI:

    Starter Content/workflows/SickOllie_NodePack.json

The workflow is already wired. Select local model, text-encoder, VAE, and LoRA
files where your installation differs from the example setup.

PROMPT AND OUTFIT LOGS
----------------------
Copy this folder:

    Starter Content/input/SickOllieLogs

into your ComfyUI input folder so the final path is:

    ComfyUI/input/SickOllieLogs

The included library contains:
- 5 prompt-log files
- 6 outfit-log files
- an empty scenes folder ready for custom scene logs

After copying the logs:
1. Restart ComfyUI.
2. Hard-refresh the browser with Ctrl+F5.
3. Reopen Prompt Core and select the desired log from its dropdown.
