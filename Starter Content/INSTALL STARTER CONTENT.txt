SICK OLLIE v2 STARTER CONTENT

WORKFLOWS
---------
Open or drag either workflow into ComfyUI:

    Starter Content/workflows/Sick Nodes v2_Classic.json
    Starter Content/workflows/Sick Nodes v2_Studio.json

Classic uses the familiar explicit-wiring workflow.
Studio uses the redesigned dashboard nodes and Auto Context.

The example workflows contain model, text-encoder, VAE, and LoRA selections
from the test system. Reassign any files that are not installed locally.

PROMPT / OUTFIT / SCENE LOGS
----------------------------
Copy this folder:

    Starter Content/input/SickOllieLogs

into the ComfyUI input folder so the final path is:

    ComfyUI/input/SickOllieLogs

The included library contains:
- 5 prompt-log files
- 6 outfit-log files
- 1 scene-log file

After copying the logs:
1. Restart ComfyUI.
2. Hard-refresh the browser if it was already open.
3. Open Prompt Core and select the desired log.
